# Trial evidence collection (existing G0–G6, no extra gates)

**G0 Source pin:** approved source SHA-256/rights, F6/F7/F1 template fingerprints, version and packet delivery receipts.

**G1 Scope:** assigned chapter/decision, read/write path allowlists, independence declarations, agent/tool identities and access control audit.

**G2 Automated lint:** hash of v2 script, baseline and challenge corpus, all diagnostics, human waiver disposition. Lint pass is never full semantic acceptance.

**G3 Independent semantic review:** timestamped original (unedited) draft SHA, claim table, citations, independent human reviewer ID and blind worksheets.

**G4 Cross-author review:** claim-by-claim overlap A/C D-14, B/C D-10/D-18 and A/B Context/Gateway; classify `AGREE`, `COMPATIBLE`, `CONTRADICTS`, `UNSUPPORTED`, `NOT_COMPARABLE` and retain original quotes.

**G5 Editorial:** qualified human decision on exact revised SHA, original defect counts preserved, rework cost recorded.

**G6 Publication:** same byte hashes and applicable approvals carried into release; does not apply to the unexecuted preparation pack.

Keep the private injection key, participant identities, source-sensitive evidence and original submissions in restricted examiner custody. Publish only approved redacted aggregate findings. Failure or missing data is `INVALID_OR_NOT_RUN`, never an inferred PASS. All times are UTC with separate active reviewer minutes, elapsed time, interruption time, and re-review time. Repairs are separately hashed versions, never overwrites of first submission.
