# Phase 8 evidence custody — existing G0–G6

- **G0:** frozen source SHA-256, human baseline attestation, rights/permissions.
- **G1:** exact chapter/F1 scope, assignment, isolated workspace, sponsor and author independence.
- **G2:** lint source SHA, regression/challenge input hashes, complete diagnostics, explicit waiver records.
- **G3:** original unedited draft SHA, separate claims ledger, blinded independent reviewer worksheet, source-level evidence.
- **G4:** joined claims A↔B Context/Gateway; A↔C D-14; B↔C D-10/D-18. Record AGREE / COMPATIBLE / CONTRADICTORY / UNSUPPORTED / NOT_COMPARABLE, severity and source.
- **G5:** human editorial decision on exact revised SHA, with original first-submission failures retained.
- **G6:** release only against same tested/approved bytes; no publication approval claimed at preparation stage.

Capture start/end UTC, active working minutes separately from interruption and review minutes, environment/model/tool versions, any coaching, source access audit, first submission digest and rework digests. Store sensitive identities, raw manuscripts and answer keys in restricted custody. Public results must be approved and redacted. Missing data is INVALID_OR_NOT_RUN, never PASS.
