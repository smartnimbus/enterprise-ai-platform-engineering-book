# Phase 4 — Canonical Knowledge Crosswalk and Authoring Governance Audit

## Files
- `PHASE-4-CANONICAL-AUTHORING-CROSSWALK-AUDIT-v1.0.md`: full audit and usage boundary
- `MASTER-AUTHORING-CROSSWALK.csv`: typed, provenance-graded links
- `CANONICAL-CONCEPT-OWNERSHIP.csv`: concept/owner matrix

- `CHAPTER-AUTHORING-CONTRACTS-58.csv`: immutable chapter identity with proposed writing scopes
- `VOCABULARY-AUTHORITY-24.csv`: source-led definitions and ambiguity controls
- `EVIDENCE-TAXONOMY-15.csv`: evidence classes, not substitute approvals
- `AUTHORING-EXCEPTIONS-AND-RISKS.csv`: unresolved crosswalk/terminology/editorial issues
- `VALIDATION-SUMMARY.json`: source hashes, counts and assertions
- `build.py`, `report.py`: reproducible offline derivation from supplied Phase 3 and frozen local files

## Usage
Do not copy an editorial proposal into a frozen source. First pin source revisions, resolve `PENDING_HUMAN_CROSSWALK_RECONCILIATION`, review vocabulary errata, and test the Chapter 13/16/Atlas pilot with independent human assessment.
