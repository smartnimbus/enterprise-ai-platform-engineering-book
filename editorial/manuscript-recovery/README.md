# Manuscript Recovery Pack

- `MANUSCRIPT-RECOVERY-ASSESSMENT.md` — editorial analysis, metrics and production decisions.
- `CHAPTER-RECOVERY-MATRIX-58.csv` — all 58 chapters, existing prose vs blueprints, recoverable inputs and missing assets.
- `CHAPTER-FACTORY-INPUT-PACKAGES-58.csv` — per-chapter mandatory, optional and prohibited source classes.
- `PRODUCTION-PRIORITY-58.csv` — per-chapter ease, reader value, dependency and hours.
- `CONTENT-REUSE-ASSESSMENT.csv` — reuse by source family and adaptation limits.
- `DIAGRAM-AND-REFERENCE-EVIDENCE-58.csv` — distinguishes figure brief from completed art.
- `SOURCE-RECOVERY-PROVENANCE.csv` — source keys and GitHub main links.
- `FORECAST-ASSUMPTIONS.json` — explicit scenario calculation inputs.

Do not infer manuscript completeness from framework-specification content. No frozen source documents are modified.
