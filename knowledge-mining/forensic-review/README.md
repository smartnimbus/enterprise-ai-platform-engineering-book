## The high-value findings

**Most portable intellectual lineage:** policy-intercepted action, scope-constrained delegated identity, explicit source provenance and disagreement, evidence-backed design/release decisions, durable operation/recovery, cost per successful outcome and lifecycle-to-exit reasoning.

**Most valuable adverse evidence:** UAF remediation report criticises claimed completion despite critical implementation risks; MemOS audit measures largely scaffold readiness rather than a finished memory engine. Both show why design intent must be distinguished from verified operation.

**Most important rights issue:** Some snapshots contain real internal enterprise data and substantial vendored third-party reference material; AEGIS contains authored book drafts and generated images. **Original archives are deliberately excluded from this research package** and must not be committed to the public book repository without clearance.

**Most important authority rule:** The frozen 4-layer/8-plane architecture, 58 chapters, 30 decisions, Meridian Fixture and Style Bible v1.2 are not superseded or modified by historical material.

## How to use the pack

1. Read `Forensic_Methodology_and_Limitations.md` and `Cross_Project_Synthesis.md`.
2. Open the dossier for a specific project; follow IA identifiers into `Intellectual_Asset_Register.csv` to the exact archived path, line and SHA-256.
3. Query `Book_Relevance_Matrix.csv` for a chapter or decision ID before planning examples.
4. Use `Master_Knowledge_Graph.graphml` for thematic exploration, not for claiming proof of deployment.
5. Apply `Repository_Import_Plan.md` gates before public use; source excerpts still require verification, confidentiality and rights clearance.

## Scope limitations

The archive corpus is too broad to assert a human-style line-by-line review of every document, all code paths, every PDF page, all source workbook rows or Git histories. All file entries were inventoried; extracted text was indexed and selected substantive first-party materials underwent detailed reading and concept extraction. The limitations are documented rather than hidden.
