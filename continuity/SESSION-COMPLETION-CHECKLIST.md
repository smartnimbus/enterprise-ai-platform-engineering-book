# Mandatory significant-session close checklist

A significant session changes a deliverable, a durable decision, a constraint, a task disposition, a substantive explanation, a reusable prompt or a handover dependency. Routine conversation with no durable value needs no commit.

- [ ] Inventory actual deliverables and new durable insights.
- [ ] Save complete deliverables, not substitutes or summaries; preserve native sources, figure captions, alt text and required attachments.
- [ ] Check authoritative source, evidence and rights; label draft/recommendation/hypothetical/unknown correctly.
- [ ] Update relevant chapter, diagram and topic notes; N/A with reason for unchanged areas.
- [ ] Update knowledge register and active decisions for genuinely new insights or dispositions.
- [ ] Update task status, existing issue/task tracking where applicable, and open questions.
- [ ] Update current state and next-session handover with exact sources, blockers, next action and scope.
- [ ] Update prompt library only for reusable changes; N/A with reason otherwise.
- [ ] Append session log entry listing deliverables, decisions, remaining gaps and verification performed.
- [ ] Commit and push through existing repository process; check remote ref and actual changed paths/content; distinguish committed/integrated/accepted.
- [ ] Report commit/link, saved files, outstanding items and any failed checks to author. If blocked, supply public-safe portable recovery packet when possible and clearly mark session incomplete.

Do not wait until a chat hits its maximum length. Capture coherent outputs incrementally. Never assume closing the chat triggers these actions. Do not mark an interrupted or failed push as complete.
