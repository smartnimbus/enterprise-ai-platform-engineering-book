# Knowledge preservation — working index

Purpose: preserve durable reasoning, rejected alternatives, editorial intent and source constraints from conversations so future contributors need not recover an entire chat. This is a lightweight implementation of the existing proposed knowledge-system blueprint, not a new authority system. Existing canonical files prevail; no architecture, chapter contract, Atlas default, fixture or review status is changed.

Start with [MASTER-KNOWLEDGE-REGISTER.md](MASTER-KNOWLEDGE-REGISTER.md). Use [capture instructions](CHAT-CAPTURE.md) after substantive work. Source documents remain in their current locations. Never put raw transcripts, personal author information, unpublished third-party feedback, employer/client details or secrets into this public repository. Private source pointers may be opaque references; do not expose private URLs or access tokens.

Read relevant chapter notes before drafting; read the actual canonical source before quoting a default or evidence field. Notes are working aids, not approval records. Use existing repository change procedures for correction and integration.

## Folder placement

- knowledge/: master index, capture instructions, cross-topic reasoning.
- editorial/notes/: chapter notes and reusable writing guidance.
- editorial/figures/: rationale and traceability; editable diagrams and renders remain at their current canonical locations until an approved relocation.
- publishing/apress/submissions/: actual commercial drafts and acquisition insights.
- decisions/: existing authoritative catalogue and display pages.
- meridian/fixture/: existing synthetic records, unchanged.
- archive/: historical public-safe material only; raw conversations retained in private storage, if available.

No empty directories or duplicate source masters are needed.
